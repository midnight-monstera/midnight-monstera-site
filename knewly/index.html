Questions

Knewly Web FAQ

Is Knewly Web free?

Yes. The Web app provides Knewly’s Free tier. Premium purchase, restoration, and management are available only through supported mobile app stores.

Do I need an account?

No. You can create, edit, study, import, export, back up, and restore local flashcards without creating an account.

Can I study offline?

Yes. After Knewly Web has loaded and its offline files are cached, core card creation and study features are designed to continue without a network connection.

Where are my flashcards stored?

They are stored locally in the browser on the device you are using. Clearing browser site data may remove them, so use Knewly’s backup and export tools regularly.

Can I import flashcards from a spreadsheet?

Yes. Copy two columns (front and back) from a spreadsheet and paste them into Bulk Add, or import a tab-separated (TSV) file as a new deck from Settings → Backup and Restore. You can review every card before saving.

Are there ready-made decks I can use?

Yes. Download a free starter deck, such as beginner Spanish, Greek and Latin roots, or US and world capitals, and import it into Knewly.

Can I move my decks to another device?

Yes. Create a backup or deck export, move that file using a destination you choose, and restore or import it on the other device.
