How to import

Two kinds of decks, two ways to import.

Text decks download as TSV files. Picture decks, which include images like maps, or pictures of your notes, download as ZIP files. Each kind has its own import option in Knewly, so check the file’s ending before you start.

Text decks

TSV file (.tsv)

  1. Download the deck’s TSV file.
  2. Open Knewly and go to Settings → Backup and Restore → Import TSV as new deck.
  3. Select the file, name the deck, review the cards in Bulk Add, and save.

Picture decks

ZIP file (.zip)

  1. Download the deck’s ZIP file. Don’t unzip it.
  2. Open Knewly and go to Settings → Backup and Restore → Import decks from backup (ZIP).
  3. Select the file and choose Import into current collection. Your other decks stay as they are.

A ZIP deck won’t open with Import TSV, and a TSV deck won’t open with the ZIP import. Knewly Free includes up to three decks, and each import adds a new deck.

Make your own

Turn any word list into flashcards.

Text decks use a simple TSV (tab-separated values) format: one card per line, with the front text, a tab, and then the back text. There is no header row. To build your own, put fronts in column A and backs in column B of a spreadsheet, then save as tab-delimited text—or copy the two columns and paste them straight into Knewly’s Bulk Add.
