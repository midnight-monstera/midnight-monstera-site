How to import

From download to study session in a minute.

Step 1

Download the TSV file

Save the deck file to your device. It’s a plain text file with one card per line.

Step 2

Import it into Knewly

Open Knewly, then go to Settings → Backup and Restore → Import TSV as new deck and select the file.

Step 3

Review and start studying

Name the deck, review the cards in Bulk Add, and save. Delete or edit any cards you don’t need first.

Knewly Free includes up to three decks. Each import creates a new deck.

Make your own

Turn any word list into flashcards.

These decks use a simple TSV (tab-separated values) format: one card per line, with the front text, a tab, and then the back text. There is no header row. To build your own, put fronts in column A and backs in column B of a spreadsheet, then save as tab-delimited text—or copy the two columns and paste them straight into Knewly’s Bulk Add.
