World Countries and Capitals flashcards

Study the capital city of every country in the world. This free deck includes 195 countries—the 193 member states of the United Nations plus the two UN observer states, Vatican City and Palestine. Where a country divides its capital functions between cities, as in Bolivia, South Africa, and Sri Lanka, the card names each one and its role. Capitals are current as of November 2026.

How to import the text deck (TSV)

From download to study session in a minute.

Step 1

Download the TSV file

Save the deck file to your device. It’s a plain text file with one card per line.

Step 2

Import it into Knewly

Open Knewly, then go to Settings → Backup and Restore → Import TSV as new deck and select the file.

Step 3

Review and start studying

Name the deck (for example, “World Countries and Capitals”), review the cards in Bulk Add, and save. Delete or edit any cards you don’t need first.

These steps are for the TSV file. For the picture version (ZIP), follow the steps under “Picture version” below. Knewly Free includes up to three decks. Each import creates a new deck.

Picture version (ZIP)

See where each country is.

The picture version has the same 195 cards. The back of each card shows the capital and a map with that country filled in red, so you learn where each country is, not just its name. Small countries and island nations are circled, and countries too small to show on a world map, like Vatican City, Tuvalu, and Nauru, are marked with a circled dot. Because it includes images, it comes as a Knewly deck backup (ZIP, 10.7 MB) instead of a TSV file.

  1. Download the World Countries and Capitals deck with maps.
  2. In Knewly, go to Settings → Backup and Restore → Import decks from backup (ZIP) and select the file.
  3. Choose Import into current collection. Your other decks stay as they are, and a new “World Countries and Capitals” deck is added.
