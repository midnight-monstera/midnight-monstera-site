US States and Capitals flashcards

Learn all 50 US state capitals with this free flashcard deck. Each card has a state on the front and its capital city on the back—great for elementary and middle school geography, quiz practice, and road-trip trivia. Watch for the tricky ones where the capital isn’t the biggest city, like Albany, Sacramento, Springfield, and Tallahassee. A picture version adds a US map to the back of each card, with the state highlighted in red.

How to import

From download to study session in a minute.

Step 1

Download the TSV file

Save the deck file to your device. It’s a plain text file with one card per line.

Step 2

Import it into Knewly

Open Knewly, then go to Settings → Backup and Restore → Import TSV as new deck and select the file.

Step 3

Review and start studying

Name the deck (for example, “US States and Capitals”), review the cards in Bulk Add, and save. Delete or edit any cards you don’t need first.

Knewly Free includes up to three decks. Each import creates a new deck.

Picture version

See where each state is.

The picture version has the same 50 cards. The back of each card shows the capital and a map of the United States with that state filled in red, so you learn where every state is, not just its name. Small states, like Rhode Island and Delaware, are also circled so they’re easy to spot. This version was suggested by a fifth grader learning the states. Because it includes images, it comes as a Knewly deck backup (ZIP, 2.3 MB) instead of a TSV file.

  1. Download the US States and Capitals deck with maps.
  2. In Knewly, go to Settings → Backup and Restore → Import decks from backup (ZIP) and select the file.
  3. Choose Import into current collection. Your other decks stay as they are, and a new “States and Capitals” deck is added.
