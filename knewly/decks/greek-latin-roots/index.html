Greek and Latin Roots flashcards

Knowing Greek and Latin roots makes unfamiliar words easier to decode—photosynthesis, chronology, and bibliophile all break into parts you can learn once and reuse. This free deck includes 500 common roots, prefixes, and suffixes with their meanings, making it useful for vocabulary building, test preparation, and science and medical terms. A leading hyphen (as in -itis) marks a word part that usually appears at the end of a word.

How to import

From download to study session in a minute.

Step 1

Download the TSV file

Save the deck file to your device. It’s a plain text file with one card per line.

Step 2

Import it into Knewly

Open Knewly, then go to Settings → Backup and Restore → Import TSV as new deck and select the file.

Step 3

Review and start studying

Name the deck (for example, “Greek and Latin Roots”), review the cards in Bulk Add, and save. Delete or edit any cards you don’t need first.

Knewly Free includes up to three decks. Each import creates a new deck.
