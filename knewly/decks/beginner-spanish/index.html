Beginner Spanish flashcards

This free beginner Spanish deck covers the words and phrases new learners use first: greetings and polite expressions, survival phrases, question words, pronouns, numbers, days, colors, family, food, places, common verbs, and describing words. Spanish is on the front of each card and English is on the back. Adjectives that change with gender list both forms, and nouns include their article (el or la) so you learn the gender along with the word.

How to import

From download to study session in a minute.

Step 1

Download the TSV file

Save the deck file to your device. It’s a plain text file with one card per line.

Step 2

Import it into Knewly

Open Knewly, then go to Settings → Backup and Restore → Import TSV as new deck and select the file.

Step 3

Review and start studying

Name the deck (for example, “Beginner Spanish”), review the cards in Bulk Add, and save. Delete or edit any cards you don’t need first.

Knewly Free includes up to three decks. Each import creates a new deck.
