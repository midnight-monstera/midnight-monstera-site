Beginner Japanese flashcards

This free beginner Japanese deck covers the words and phrases new learners use first: greetings and polite expressions, survival phrases, question words, pointing words, numbers, days, colors, family, food, places, common verbs, and describing words. Japanese is on the front of each card and English is on the back. Words usually written in kanji show the kanji first, with the hiragana reading in parentheses underneath; words usually written in hiragana or katakana appear just as they’re normally written.

How to import

From download to study session in a minute.

Step 1

Download the TSV file

Save the deck file to your device. It’s a plain text file with one card per line.

Step 2

Import it into Knewly

Open Knewly, then go to Settings → Backup and Restore → Import TSV as new deck and select the file.

Step 3

Review and start studying

Name the deck (for example, “Beginner Japanese”), review the cards in Bulk Add, and save. Delete or edit any cards you don’t need first.

Knewly Free includes up to three decks. Each import creates a new deck.
